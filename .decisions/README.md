# Decisões Arquiteturais Permanentes

Este diretório armazena os registros de decisões arquiteturais (ADRs - Architecture Decision Records) e direcionamentos técnicos do projeto.

Em conformidade com o `AGENTS.md` (Seção 36.1), as decisões devem ser registradas aqui para separar o histórico de decisões do projeto da documentação oficial de uso e contratos (`docs/`).

## Como registrar uma decisão

Crie um arquivo Markdown para cada decisão técnica relevante, numerado de forma sequencial, por exemplo: `0001-escolha-do-banco-de-dados.md`.

**Estrutura sugerida:**
1. **Contexto:** Qual é o problema ou necessidade?
2. **Decisão:** Qual foi a solução adotada?
3. **Justificativa:** Por que essa solução foi escolhida em detrimento das alternativas (trade-offs)?
4. **Consequências:** Qual o impacto dessa decisão no projeto?
